# Customer Support AI Platform

A project for learning to build a customer support application
using Python, SQL, machine learning, and AI.

## Current functionality

- Displays a welcome message and the developer's name.

## Planned features

- Load and validate support tickets.
- Analyze support trends.
- Classify tickets using machine learning.
- Answer questions using support documents.
- Add authentication, testing, and deployment.

## Run the application

Requires Python 3.12.

Run `python main.py` from the project folder.
